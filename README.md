# Folinq PDF

在本机阅读、编辑、整理和转换 PDF。支持 Windows 便携版，并提供 Android 预览版。

[下载最新版](https://github.com/ShanGuoP/Folinq/releases/latest) · [反馈问题](https://github.com/ShanGuoP/Folinq/issues)

## 下载与安装

### Windows

1. 在下载页面选择名称包含 `windows-x64` 的 ZIP 压缩包。
2. **完整解压**，打开 `Folinq-PDF` 文件夹，双击 `FolinqPDF.exe`。
3. 保留启动程序旁的 `runtime` 文件夹，里面包含运行所需的文件。

无需安装。升级时，将新版本完整解压到新文件夹，本机已有的项目、草稿和编辑历史会继续保留。

### Android 预览版

下载名称包含 `android-arm64-preview` 的 APK，在 **Android 7.0 及以上、ARM64** 设备上安装。根据系统提示，允许安装来自下载应用的文件。

安卓版目前使用开发签名，功能少于 Windows 版，尚未完成真机验收。需要可靠处理重要文件时，建议先保留原件，并核对导出结果。

## 可以做什么

- **阅读 PDF**：连续滚动、缩放、缩略图跳页；Windows 还支持搜索、复制和多文档切换。
- **修改内容**：编辑可识别的原生文字，添加文字和图片，移动、缩放、替换或删除对象。
- **整理页面**：插入、删除、旋转、调整顺序、合并，以及按页码范围拆分导出。
- **添加标记**：高亮、下划线、注释、自由绘画和图形手签。
- **管理文档**：通过封面卡片查找最近文档，将多份 PDF 放入项目分组，查看和恢复编辑历史。
- **识别扫描件**：Windows 本机 OCR 可复制识别文字或添加可搜索文字层；也可主动开启在线 OCR 后导出。
- **转换格式**：导出 PDF、PNG、JPG、TXT、Markdown 和 Word；Windows 还可将图片、TXT、基础 Markdown 和 DOCX 转成 PDF。
- **生成脱敏副本**：框选需要遮住的内容，导出整份转为图片页面的 PDF 副本。

以上为 Windows 的主要功能。Android 当前支持连续阅读、双指缩放、原生文字与图片属性编辑、撤销重做、插入空白页、旋转页面，以及另存、导出和系统分享。移动端尚未提供完整的项目与历史界面、搜索选字、新增文字与图片、绘画手签、脱敏及全部页面管理入口。

## 开始使用

### 打开与编辑

Windows 中可点击打开文件、按 `Ctrl+O`，或将一份或多份 PDF 拖入窗口。也可以将 PDF 拖到 `FolinqPDF.exe` 图标上启动。

打开文档后，从顶部「编辑」菜单选择文字、图片、批注等工具。点击页面中的文字或图片，可以修改其属性。修改扫描图片里的字，不能直接使用原生文字编辑，请先参考下方 OCR 说明。

Android 中通过系统文档选择器导入 PDF，在底部切换阅读、编辑、页面和导出。导入的文件会复制到应用内，外部原件保留；修改后请通过另存或导出保存到自己选择的位置。

### 保存与历史

| 操作 | Windows 快捷键或入口 |
| --- | --- |
| 打开 PDF | `Ctrl+O` |
| 保存到源文件 | `Ctrl+S` |
| 另存为新文件 | `Ctrl+Shift+S` |
| 放大或缩小 | `Ctrl+滚轮` |
| 查看和恢复旧版本 | 编辑页右上角「历史版本」 |

保存会先应用尚未提交的文字修改。如果源文件被其他程序修改，会提示冲突。需要保留原件时，请选择「另存为」。

草稿和工作记录会保存在本机。程序意外退出后，可重新打开并恢复已保存的工作状态；尚未成功保存的输入仍可能丢失。同一份工作记录请勿在多个窗口同时恢复。

恢复历史版本后可以继续编辑；需要写回原文件时，再按 `Ctrl+S`。导出完成后会显示保存位置。Windows 会记住上次使用的输出目录；遇到同名导出文件，会添加编号以保留已有文件。

### 最近文档与项目

在首页的卡片菜单中选择「删除记录（保留源文件）」，可以移除最近记录，不会删除原 PDF。也可以撤销移除，或重新打开 PDF。

删除项目分组后，其中的 PDF 会回到独立文档列表，源文件和编辑历史保留。

## 导出 Word、Markdown 和图片

打开导出窗口，选择格式、页面范围和保存位置。

**Word** 提供三种方式：

- **保留版式（可编辑）**：尽量保留文字、字体、页面位置、图片和有边框的表格，适合小幅修改。文字较长时，可能需要在 Word 中调整位置和大小。
- **便于编辑（自动排版）**：按阅读顺序生成段落、标题、列表和表格，适合继续写作；换行和页数可能与原 PDF 不同。
- **仅提取文字**：提取正文，便于重新排版。

Windows 提供上述 Word 选项，Android 当前提供自动排版 Word 导出。扫描件需要先做 OCR，或在导出时启用在线 OCR。

**Markdown** 可以保留标题、列表、表格和原有图片，也可只提取文字或导出页面图片。配套图片需要与 Markdown 一起移动或发送；在线 OCR 和 Android 的结构化 Markdown 会打包为 ZIP。

**PNG / JPG** 适合将页面作为图片使用。Android 当前支持单页图片导出。

复杂多栏、公式、特殊字体、旋转文字和不规则表格可能无法准确还原，转换后请核对内容与排版。

## 扫描件与 OCR

### Windows 本机识别

本机 OCR 使用 Windows 已安装的识别语言，可复制文字或为扫描页添加可搜索文字层。常规 PDF 处理与本机 OCR 无需上传文档。

OCR 不会直接替换扫描图片里的字，识别结果也需要校对。

### 在线识别后导出

Windows 和 Android 的 Word、Markdown、TXT 导出窗口均提供「在线 OCR · PaddleOCR」，**默认关闭**。适合没有文字层的扫描 PDF。

1. 打开在线 OCR 开关。
2. 使用 AI Studio 服务时，点击「填入官方地址」，填写自己的 Token 和服务支持的模型名称。默认模型为 `PaddleOCR-VL-1.6`，可手动修改。使用自部署服务时，填写完整的文档解析地址，并按服务要求选择鉴权方式。
3. 选择页面范围并导出。每次最多 100 页、25 MB，超过时请分批处理。

开启在线 OCR 并点击导出后，**所选页面会上传到你填写的服务**，可能消耗服务额度。软件不提供共享密钥；服务地址和 Token 仅在本次运行中保留。

在线 Word 会生成可编辑的标题、列表、表格和配图；Markdown 连同配图保存为 ZIP；TXT 为纯文字。在线识别按阅读顺序重新排版，不保证恢复原稿的精确位置。

取消或超时会停止本机等待，云端任务可能仍在继续。同一次运行中，文档、页码、接口、模型和 Token 均未改变时，可再次导出以继续等待已有的异步任务。软件不会自动重试付费请求。

连接自部署服务时，请使用设备能访问的地址；手机上的 `localhost` 指手机自身。公网服务建议使用 HTTPS。

## 使用限制

- 原位文字编辑主要支持顶层原生文字对象；扫描图片、嵌套文字和加密 PDF 暂不支持直接修改。
- 图形手签是页面上的笔迹图形，不是数字证书签名。
- 脱敏副本会将整份文档转为图片页面，不保留可选文字、表单或附件；导出后请核对遮盖范围。
- 交互表单、数字证书签名、复杂格式转换及大文件处理仍有待完善。
- 在线 OCR 需要自行准备服务访问权限；识别文字和转换排版均需人工核对。

## 常见问题

**Windows 启动失败或提示缺少文件？**

请先完整解压 ZIP，再运行 `FolinqPDF.exe`，并确认旁边保留了完整的 `runtime` 文件夹。不要在压缩包内直接运行，也不要只复制启动程序。

**为什么点不到 PDF 里的文字？**

页面可能是扫描图片，或文字位于暂不支持编辑的嵌套对象中。扫描件可先使用 OCR，再复制文字或导出为 Word。

**在哪里查看版本？**

点击左上角图标或「Folinq PDF」打开关于窗口；Android 可在菜单中选择「关于 Folinq PDF」。

**如何反馈问题？**

在 [GitHub Issues](https://github.com/ShanGuoP/Folinq/issues) 提供软件版本、操作系统、复现步骤和报错截图。如果方便，可附上一份不含隐私的最小 PDF 样本。请勿公开服务 Token 或含敏感信息的文档。
